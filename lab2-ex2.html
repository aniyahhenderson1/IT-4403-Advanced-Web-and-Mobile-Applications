jQuery ready() and Event Handling

Hide Paragraphs

Paragraph one: clicking the first button hides this paragraph.

Paragraph two: clicking the second button hides this paragraph.

Reload the page to bring the paragraphs back.

What I Observed

Part A: both paragraphs

Both buttons first called $("p").hide(), so either button hid both paragraphs.

Part B: individual paragraphs (the working version on this page)

$(document).ready(function () {
    $("#btn1").click(function () { $("#p1").hide(); });
    $("#btn2").click(function () { $("#p2").hide(); });
});

Part C: removing $(document).ready()

  • Does it still work? It depends on where the script is. In the <head>, the buttons do not exist yet when the code runs, so $("#btn1") finds nothing and the clicks never attach. The buttons do nothing.
  • Does location matter? Yes. The same code placed at the end of <body>, after the buttons, works without ready(), because the elements already exist.
  • Why is it useful? ready() waits until the DOM is fully built, so the script works wherever it is placed.
