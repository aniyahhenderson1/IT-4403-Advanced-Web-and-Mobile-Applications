jQuery is a lightweight, “write less, do more” JavaScript library. Its purpose is to make it much easier to use JavaScript on your website. jQuery takes common tasks that need many lines of JavaScript and wraps them into methods you can call with a single line of code. It also simplifies things like AJAX calls and DOM manipulation.
